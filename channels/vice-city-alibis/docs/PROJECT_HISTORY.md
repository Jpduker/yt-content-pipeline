# Project history
## Initial idea
The user proposed static-transition Shorts based on GTA VI characters, places and world, with enthusiastic crime plots, in a new channel.
The discussion separated technical production from audience demand, YouTube monetization and Rockstar IP permission. Static visual storytelling can carry a narrative; a repetitive low-value slideshow is a different production outcome. Existing Rockstar fan guidance is not a blanket commercial fiction-series license.
The user confirmed both actual GTA VI characters and the world/crime atmosphere are essential. A separate GTA audience is the aim.

## Pilot v1 — The Wrong Getaway Car
A complete 36.6-second 1080×1920 illustrated pilot was created: seven full frames/eight compositions, narration, captions, gentle reframing and synthesized environmental sound.
Plot: Lucia finds a recent surveillance photo in their stolen car. Their fixer calls them to the docks. Cash and a tracker reveal a setup. They send the car on a tow truck, tip off police and keep the money.
A generated dock scene mistakenly put the heroes in the supposedly empty car; that was corrected.
A background duplicate car at the waterfront was removed.
The first cash insert was an economical crop of the waterfront payoff, which was later replaced with a proper car-interior scene.
Feedback: world cool/nice; picture holding, wheels and minor details need improvement. Narration/voice rated 0/10.

## Pilot v2
Rebuilt the photo shots to face Lucia and the camera coherently; photo depicts Lucia alone.
Revised tire, rim, flatbed support and tie-down geometry.
Reframed the fixer scene and maintained an empty car.
Generated a dedicated under-seat cash/tracker insert.
Rewrote the spoken script with a direct photo hook and a cleaner payday ending.
ElevenLabs Eleven v4 produced full Liam and Laura versions at native pitch/timing: approximately 33 and 34.5 seconds.
Feedback: both narration versions feel great; user prefers male Liam. Record and preserve this approval.

## Channel development / v3 request
The user asked to save this project under the Windows YouTube/channels folder, choose a distinctive channel name and description, create a logo, and build a consistent character/world asset system.
The user requested richer scene-specific music/SFX and proposed alternating between narrator-led and character-conversation stories.
The user nominated Lara (vChnJZ1Cu89g2XXumPfT) as a main-female candidate.
Selected name: Vice City Alibis.
This Linux workspace cannot write directly to the user's unmounted Windows Downloads path. A complete folder package and Windows installer are supplied instead.
Eleven Music composition returned HTTP 402 paid_plan_required; six ElevenLabs SFX generations succeeded.
Lara was found in the shared voice library and added to saved voices, but her TTS request returned HTTP 402 because free accounts cannot use library voices through the API.
V3 therefore uses a new original four-section composed score plus generated SFX and the unchanged approved Liam performance. It is a sound-quality review, not publication approval.
