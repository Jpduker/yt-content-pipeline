# Creating the channels (Jp, 2026-11-08)
Plan: one Google account, separate channels for different audiences. Each extra channel is a "brand account" channel:
YouTube → avatar → Settings → "Add or manage your channel(s)" → "Create a channel". (Menu labels can change; if they differ, search
YouTube Help for "create a channel with a brand account".) Handles: YouTube checks availability live when you type it; 3–30 characters,
letters, numbers, ".", "_", "-". Pick the first free option below. Nothing here is verified available.
