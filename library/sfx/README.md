# Real sound-effect library (for the real-sfx skill)
Put recorded SFX packs here, one folder per pack, each with its licence file. Register: `python tools/clipwing-skills/skills/real-sfx/scripts/setup.py add-library <name> library/sfx/<pack> --tier main --index`.
Free sources with commercial-friendly licences (read each licence before use):
- Sonniss "GDC Game Audio Bundle" (royalty-free, commercial use allowed; several GB per year's bundle).
- Freesound.org with the CC0 filter (CC BY also fine if credited in the description).
- Pixabay sound effects, Mixkit sound effects (their own free licences).
- uisfx (CC0 UI cues) installs with `setup.py init --uisfx`.
Never rip sounds from YouTube/Instagram videos.
